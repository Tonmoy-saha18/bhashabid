# Contributing to Bhashabid

We welcome contributions to the Bengali linguistic knowledge base, deterministic tools, and evaluation benchmarks.

## Contribution Guidelines
1. **Spec Requirement**: All PRs must reference an existing requirement in `specs/02-requirements.md` or propose a spec change in `specs/CHANGELOG.md`.
2. **Deterministic Tools**: Add unit tests for every new rule. Zero regression policy.
3. **Knowledge Cards**: All submitted cards must include source attribution, positive/negative examples, and default to `data-supported` status pending human review.
4. **License Compliance**: Do not paste copyrighted texts into cards or issues.
