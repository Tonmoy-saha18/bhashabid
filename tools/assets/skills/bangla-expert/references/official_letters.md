# Official Applications & Epistolary Guide (দাপ্তরিক আবেদন ও চিঠিপত্র নির্দেশিকা)

## 1. Administrative Applications & Petitions (সরকারি ও প্রাতিষ্ঠানিক দরখাস্ত)
- **Header**:
  ```
  বরাবর,
  [প্রাপকের পদবি]
  [দপ্তর / প্রতিষ্ঠান]
  [ঠিকানা / জেলা]
  ```
- **Subject**: `বিষয়: [সংক্ষিপ্ত ও স্পষ্ট উদ্দেশ্য]`
- **Salutation**: `জনাব,` বা `মহোদয়,` (Never 'প্রিয় মহাশয়' or 'সম্মানিত স্যার').
- **Opening formula**: `বিনীত নিবেদন এই যে, [মূল বক্তব্য / কারণ]...`
- **Concluding prayer**:
  `অতএব, মহোদয়ের সমীপে বিনীত প্রার্থনা, উক্ত বিষয়টি বিবেচনা করে প্রয়োজনীয় ব্যবস্থা গ্রহণে আপনার সদয় মর্জি হয়।`
- **Closing**: `বিনীত / নিবেদক,` -> `[নাম ও পদবি / এলাকাবাসীর পক্ষে]`

## 2. Letter Registers (সামাজিক ও ব্যক্তিগত পত্র)
- **To Seniors (গুরুজন)**:
  - সম্ভাষণ: `শ্রদ্ধেয় বাবা / শ্রদ্ধেয়া মা / শ্রদ্ধাস্পদেষু`
  - পত্রারম্ভ: `আমার ভক্তিপূর্ণ সালাম / প্রণাম গ্রহণ করবেন।`
  - সমাপ্তি: `প্রণামান্তে / আপনার স্নেহধন্য / বিনীত`
- **To Peers/Friends (বন্ধু)**:
  - সম্ভাষণ: `প্রিয় [নাম] / সুপ্রিয় [নাম],`
  - পত্রারম্ভ: `অনেক দিন তোর কোনো খোঁজ নেই...`
  - সমাপ্তি: `ইতি, তোরই বন্ধু [নাম]`
- **To Juniors (কনিষ্ঠ)**:
  - সম্ভাষণ: `স্নেহের [নাম] / কল্যাণীয়াসু,`
  - সমাপ্তি: `শুভাকাঙ্ক্ষী / তোমার স্নেহের...`
- **Corporate/Professional**:
  - সম্ভাষণ: `সুধী / প্রিয় সহকর্মী / মহোদয়,`
  - সমাপ্তি: `ধন্যবাদান্তে / শুভকামনাসহ` (Never 'আপনার বিশ্বস্তভাবে')
