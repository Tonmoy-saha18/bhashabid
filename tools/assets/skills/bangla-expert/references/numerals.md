# Bengali Numerals Reference Guide

## 1. 0-99 Irregular Number Words
- 0-9: শূন্য, এক, দুই, তিন, চার, পাঁচ, ছয়, সাত, আট, নয়
- 10-19: দশ, এগারো, বারো, তেরো, চৌদ্দ, পনেরো, ষোলো, সতেরো, আঠারো, উনিশ
- 20-29: বিশ, একুশ, বাইশ, তেইশ, চব্বিশ, পঁচিশ, ছাব্বিশ, সাতাশ, আঠাশ, ঊনত্রিশ
- 30-39: ত্রিশ, একত্রিশ, বত্রিশ, তেত্রিশ, চৌত্রিশ, পঁয়ত্রিশ, ছত্রিশ, সাঁইত্রিশ, আটত্রিশ, ঊনচল্লিশ
- 40-49: চল্লিশ, একচল্লিশ, বিয়াল্লিশ, তেতাল্লিশ, চুয়াল্লিশ, পঁয়তাল্লিশ, ছেচল্লিশ, সাতচল্লিশ, আটচল্লিশ, ঊনপঞ্চাশ
- 50-59: পঞ্চাশ, একান্ন, বায়ান্ন, তিপ্পান্ন, চুয়ান্ন, পঞ্চান্ন, ছাপ্পান্ন, সাতান্ন, আটান্ন, ঊনষাট
- 60-69: ষাট, একষট্টি, বাষট্টি, তেষট্টি, চৌষট্টি, পঁয়ষট্টি, ছেষট্টি, সাতষট্টি, আটষট্টি, ঊনসত্তর
- 70-79: সত্তর, একাত্তর, বাহাত্তর, তিয়াত্তর, চুয়াত্তর, পঁচাত্তর, ছিয়াত্তর, সাতাত্তর, আটাত্তর, ঊনআশি
- 80-89: আশি, একাশি, বিরাশি, তিরাশি, চুরাশি, পঁচাশি, ছিয়াশি, সাতাশি, আটাশি, ঊননব্বই
- 90-99: নব্বই, একানব্বই, বিরানব্বই, তিরানব্বই, চুরানব্বই, পঁচানব্বই, ছিয়ানব্বই, সাতানব্বই, আটানব্বই, নিরানব্বই

## 2. South Asian Number Grouping
- Group format: X,XX,XX,XXX (3 digits at end, 2 digits thereafter)
- Examples: 1,00,000 (এক লাখ), 1,00,00,000 (এক কোটি), 12,34,567 (১২,৩৪,৫৬৭)

## 3. Fractions & Decimals
- 0.25 = এক-চতুর্থাংশ (পোয়া / সিকি)
- 0.50 = অর্ধেক (আধ)
- 1.25 = সোয়া এক; 1.50 = দেড়; 1.75 = পৌনে দুই; 2.50 = আড়াই; 3.50 = সাড়ে তিন
- Decimals: Read digit by digit after 'দশমিক' (৩.১৪ -> তিন দশমিক এক চার)

## 4. Date Ordinals
- ১লা (পয়লা), ২রা (দোসরা), ৩রা (তেসরা), ৪ঠা (চৌঠা), ৫ই (পাঁচই) ... ৩১শে (একত্রিশে)
